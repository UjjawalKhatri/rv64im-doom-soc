# Authors

This project was designed, implemented and brought up by two people.

**Ujjawal Khatri** — [@UjjawalKhatri](https://github.com/UjjawalKhatri)  
RTL: RV64IM pipeline, hazard/forwarding logic, SoC interconnect, DDR arbiter, native AXI3 master, VGA and framebuffer peripherals, constraints, simulation environment and the Vivado build flow.

**Molik Rajvanshi** — [@MolikRajvanshi](https://github.com/MolikRajvanshi)

Both authors jointly debugged the two microarchitectural bugs documented in [docs/ENGINEERING_LOG.md](docs/ENGINEERING_LOG.md).
